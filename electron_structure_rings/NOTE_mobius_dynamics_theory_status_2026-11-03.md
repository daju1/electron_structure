## 1. Главный теоретический вывод [источник + вывод]
deWit 1973 II, ур. (5.5): скачок на поверхности дискретного дефекта — жёсткое движение
[u] = b + Ω×(x − x⁰). Локальный вектор Бюргерса вдоль линии меняется ЛИНЕЙНО по координате.
Закон «b поворачивается на π за обход при |b| = const» (мёбиус) этого вида НЕ имеет.
⇒ Мёбиус-кольца не являются дефектами Вольтерры линейной теории (и T(3) Лазара).
Они допустимы только:
- в нелинейной теории конечных поворотов (сноска 3 у deWit) — путь пользователя через тензор
  Альманси и строгий вывод уравнений в координатах Эйлера (equation_of_motion_in_Euler_coordinates);
- в среде Коссера (конечный поворот репера, ср. Васильев);
- для директорного поля ±b (полуцелые дисклинации k = ½, Kleman–Friedel 2008).

Уравнения непрерывности deWit (4.3)–(4.4): дислокации кончаются только на дисклинациях;
дисклинации внутри тела не кончаются. Законы переноса α, θ с движением дефектов —
Fressengeas–Taupin 2020 (ур. 88, 93–94): движущаяся дисклинация порождает поток дислокаций
через пластическую кривизну κ̇ᵖ = θ × V_θ.

## 2. Статус конфигураций
| вариант | статус | условие / проблема |
|---|---|---|
| glide, T(3) | согласуется | b постоянен (deWit 3.6); бегущей особой точки нет |
| glide, Коссер | при допущении | поворот b = поворот репера или ток дислокаций между кольцами; Δb и q_m нет; бозон |
| Мёбиус A (b стоит, бежит шов) | противоречие в текущем виде | шов со скачком b требует дисклинации в шве (4.3); движущаяся дисклинация рождает ток дислокаций; сеть пары не замыкается (п. 3) |
| Мёбиус B (директор вращается с ω/2) | при допущении | b — директор; разрез ненаблюдаем; Δb нет ⇒ q_m не в шве |
| Мёбиус C (ω/2 + бегущий шов) | согласуется как контрпример | период 2π — бозон, не электрон |

Все мёбиус-варианты в трёх плоскостях (r,z), (r,τ), (z,τ): A и B дают b→−b за 2π и возврат за 4π [посчитано].
Плоскости с компонентой b вне плоскости скольжения требуют переползания (в кристалле — только диффузия;
в эфире запрета нет) [вывод].

## 3. Пара без суммарного вектора Бюргерса [посчитано]
Контур вокруг обоих колец, max по кольцу и по φ ∈ [0, 4π):
- полюса в противофазе (180°): |b_N + b_S|max = √2·b₀ ≈ 1.414 b₀ для A, B, C во всех трёх плоскостях;
- перебор законов твиста S: ψ_S = a·χ + c·φ + δ, a ∈ {±½}, c ∈ {±½, ±3/2}, знак ±, δ шагом 15° —
  минимум остаётся √2·b₀. Ни один закон твиста S не гасит сумму при противофазе;
- для директора (сравнение с точностью до знака) — тоже не совпадает;
- полюса в фазе (0°): сумма = 0 точно для A, B, C во всех плоскостях.

Вывод [вывод]: при противофазе полюсов (требование модели, draw_scheme) мёбиус-пара несёт
суммарный b ~ √2 b₀ ⇒ дальнодействующее поле одиночной дислокации, а не нейтральный диполь.
Нейтральность требует либо полюсов в фазе (но тогда нет вращающегося поперечного диполя),
либо дополнительного дефекта (перемычка/дисклинация), компенсирующего сумму. Это открытая проблема.

## 4. Открытые вопросы
1. Где живёт q_m в варианте B (Ω-часть, поток ∮ω = 2πν, точка b ∥ e_z?).
2. Как совместить противофазу полюсов с нулевым суммарным b пары.
3. Динамика: Kossecka (не скачана), Lazar — dynamics of dislocations and disclinations; приложить
   законы переноса Fressengeas–Taupin к вращающемуся кольцу.
4. Модуль b в шве: «поворотом» или «через ноль» — энергия не посчитана.
5. Нелинейная теория (Альманси/Эйлер): допускает ли она поворот b на π за обход как решение.

## 5. Можно ли погасить сумму пары одним дефектом Вольтерры? [посчитано, 3 ноя вечер]
Сумма S(θ) = b_N + b_S подогнана МНК видом a + Ω×x(θ) (трансляция + поворот — общий вид скачка
deWit 5.5) для A и B во всех трёх плоскостях и φ ∈ {0.3, 1.7, 3.1, 5.0}:
остаток max ≈ 0.9–1.7 b₀ при |S|max ≈ 1.41 b₀ — подгонка почти ничего не убирает.
Гармоники S по азимуту (A, (r,z)): заметны n = 0, 1, 2, 3, 4 — у Вольтерры только n ≤ 1.
Вывод [вывод]: компенсирующий дефект не может быть одной классической линией (ни дислокацией вдоль
оси, ни дисклинацией); нужен распределённый дефект с высокими азимутальными гармониками —
по сути ещё одно (или два) мёбиус-подобных кольца, либо нелинейная теория, где S сама обращается в ноль.
