## 1. Главный теоретический вывод [источник + вывод]
deWit 1973 II, ур. (5.5): скачок на поверхности дискретного дефекта — жёсткое движение
[u] = b + Ω×(x − x⁰). Локальный вектор Бюргерса вдоль линии меняется ЛИНЕЙНО по координате.
Закон «b поворачивается на π за обход при |b| = const» (мёбиус) этого вида НЕ имеет.
⇒ Мёбиус-кольца не являются дефектами Вольтерры линейной теории (и T(3) Лазара).
Они допустимы только:
- в нелинейной теории конечных поворотов (сноска 3 у deWit) — путь пользователя через тензор
  Альманси и строгий вывод уравнений в координатах Эйлера (equation_of_motion_in_Euler_coordinates);
- в среде Коссера (конечный поворот репера, ср. Васильев);
- для директорного поля ±b (полуцелые дисклинации k = ½, Kleman–Friedel 2008).

Уравнения непрерывности deWit (4.3)–(4.4): дислокации кончаются только на дисклинациях;
дисклинации внутри тела не кончаются. Законы переноса α, θ с движением дефектов —
Fressengeas–Taupin 2020 (ур. 88, 93–94): движущаяся дисклинация порождает поток дислокаций
через пластическую кривизну κ̇ᵖ = θ × V_θ.

## 2. Статус конфигураций
| вариант | статус | условие / проблема |
|---|---|---|
| glide, T(3) | согласуется | b постоянен (deWit 3.6); бегущей особой точки нет |
| glide, Коссер | при допущении | поворот b = поворот репера или ток дислокаций между кольцами; Δb и q_m нет; бозон |
| Мёбиус A (b стоит, бежит шов) | противоречие в текущем виде | шов со скачком b требует дисклинации в шве (4.3); движущаяся дисклинация рождает ток дислокаций; сеть пары не замыкается (п. 3) |
| Мёбиус B (директор вращается с ω/2) | при допущении | b — директор; разрез ненаблюдаем; Δb нет ⇒ q_m не в шве |
| Мёбиус C (ω/2 + бегущий шов) | согласуется как контрпример | период 2π — бозон, не электрон |

Все мёбиус-варианты в трёх плоскостях (r,z), (r,τ), (z,τ): A и B дают b→−b за 2π и возврат за 4π [посчитано].
Плоскости с компонентой b вне плоскости скольжения требуют переползания (в кристалле — только диффузия;
в эфире запрета нет) [вывод].

## 3. Пара без суммарного вектора Бюргерса [посчитано]
Контур вокруг обоих колец, max по кольцу и по φ ∈ [0, 4π):
- полюса в противофазе (180°): |b_N + b_S|max = √2·b₀ ≈ 1.414 b₀ для A, B, C во всех трёх плоскостях;
- перебор законов твиста S: ψ_S = a·χ + c·φ + δ, a ∈ {±½}, c ∈ {±½, ±3/2}, знак ±, δ шагом 15° —
  минимум остаётся √2·b₀. Ни один закон твиста S не гасит сумму при противофазе;
- для директора (сравнение с точностью до знака) — тоже не совпадает;
- полюса в фазе (0°): сумма = 0 точно для A, B, C во всех плоскостях.

Вывод [вывод]: при противофазе полюсов (требование модели, draw_scheme) мёбиус-пара несёт
суммарный b ~ √2 b₀ ⇒ дальнодействующее поле одиночной дислокации, а не нейтральный диполь.
Нейтральность требует либо полюсов в фазе (но тогда нет вращающегося поперечного диполя),
либо дополнительного дефекта (перемычка/дисклинация), компенсирующего сумму. Это открытая проблема.

2. Как совместить противофазу полюсов с нулевым суммарным b пары.

4. Модуль b в шве: «поворотом» или «через ноль» — энергия не посчитана.

## 5. Можно ли погасить сумму пары одним дефектом Вольтерры? [посчитано, 3 ноя вечер]
Сумма S(θ) = b_N + b_S подогнана МНК видом a + Ω×x(θ) (трансляция + поворот — общий вид скачка
deWit 5.5) для A и B во всех трёх плоскостях и φ ∈ {0.3, 1.7, 3.1, 5.0}:
остаток max ≈ 0.9–1.7 b₀ при |S|max ≈ 1.41 b₀ — подгонка почти ничего не убирает.
Гармоники S по азимуту (A, (r,z)): заметны n = 0, 1, 2, 3, 4 — у Вольтерры только n ≤ 1.
Вывод [вывод]: компенсирующий дефект не может быть одной классической линией (ни дислокацией вдоль
оси, ни дисклинацией); нужен распределённый дефект с высокими азимутальными гармониками —
по сути ещё одно (или два) мёбиус-подобных кольца, либо нелинейная теория, где S сама обращается в ноль.

## 6. Результаты 3 ноя (вечер) — ноутбук verification/verification_mobius_dynamics.ipynb, все проверки OK
1. Геометрия пары [посчитано + формула]: при сдвиге особой точки S на Δ
   max|b_N+b_S| = 2b₀·max(|cos Δ/4|, |sin Δ/4|) при Δ≠0, и 0 при Δ=0. Минимум при Δ≠0 — именно
   противофаза Δ=π: √2·b₀, причём одинаково во всех точках кольца. Подбором сдвига не погасить.
2. ТЕОРЕМА нейтральности [вывод, проверено перебором]: Σ_k b_k ≡ 0 ⇔ в каждой азимутальной позиции
   особых точек Σ s_k = 0. Тогда поперечный дипольный момент особых точек = 0, остаётся только осевой.
   ⇒ Нейтральность по Бюргерсу и вращающийся поперечный диполь (draw_scheme) НЕСОВМЕСТИМЫ для мёбиус-колец
   данного вида. 3 кольца — нейтральных нет; 4 кольца — есть, но тоже без поперечного диполя.
   Побочное следствие: нейтральная конфигурация не излучает дипольно (ср. τ~10⁻¹⁸ с у пары).
3. Нелинейная теория (кинематика) [вывод]: в SO(3)⋉T(3) (Kadić–Edelen, Katanaev–Volovich) закон ψ=χ/2
   = голономия конечного поворота Q=R_n(π) при обходе петли, сцепленной с π-дисклинацией:
   (r,τ) — клиновая π-дисклинация вдоль оси спина (аналог k=½); (r,z), (z,τ) — π-дисклинации кручения.
   Q²=I в SO(3), двузначный лифт в SU(2) → спин ½. Это кинематика; решением нелинейных уравнений
   (Альманси/Эйлер) не проверено.
   Новый взгляд на сумму пары: при голономии b_N и b_S измеряются в разных реперах, и простая сумма
   b_N+b_S может быть некорректной мерой — сравнивать надо после параллельного переноса. Открыто.
4. Законы переноса (Fressengeas–Taupin, ур. 88, 93–94) [оценка]: κ̇ᵖ = θ×V.
   B: дисклинация голономии на оси неподвижна → κ̇ᵖ=0, вращение b — поворот репера, без рождения дислокаций.
   A, C: бегущий шов (дисклинация ∥ e_z движется по e_τ) → поток дислокаций |κ̇ᵖ| ~ π·ωR, с сопротивлением
   B_θ — диссипация. По динамике вариант B предпочтительнее.

## 7. Результаты 3 ноя (поздний вечер) — ноутбук, разделы 8–11, все OK
1. Перенос репера [посчитано]: угол β(θ), переводящий b_S в −b_N, равен ±90° со скачком знака на полюсах (A)
   или на разрезе (B). Гладкой связностью остаток √2·b₀ не гасится; нужна дисклинация с углом 90° между
   кольцами, меняющая знак, — т.е. ещё один дефект.
2. ПОПРАВКА к теореме п. 6.2 [посчитано]: она верна только при РАВНЫХ радиусах. Мёбиус-закон b(θ) зависит
   от азимута, не от радиуса ⇒ вложенные кольца N(R,0), S(R,π), N′(ρR,π), S′(ρR,0) нейтральны по Бюргерсу
   (Σb = 0 для A/B/C во всех плоскостях) и имеют вращающийся поперечный диполь p⊥ = 2(1−ρ)R ≠ 0.
   ⇒ Кандидат: электрон = 4 вложенных мёбиус-кольца (две пары разного радиуса). Спин/статистика такой
   системы, энергия, устойчивость при ρ → 1 — не исследованы. [гипотеза]
3. Нелинейность [посчитано]: для конечного поворота F = R(ψ) линейная деформация ε = 1 − cos ψ (= 2 при ψ = π),
   а тензор Альманси e = ½(I − F⁻ᵀF⁻¹) ≡ 0. Поворот репера на π вдоль мёбиус-кольца не стоит деформации
   только в эйлеровой нелинейной теории — подтверждает тезис автора. Полное решение уравнений движения
   (equation_of_motion_in_Euler_coordinates) для кольца — не сделано.
4. SU(2) [наблюдение]: подъём π-поворота U = −iσ_z; пара одинаково закрученных: U² = −I; мёбиус + анти-мёбиус: +I;
   4 одинаковых: +I. К статистике при повороте всей частицы на 2π напрямую не сводится — открыто.
Визуализация: viz/model3d_all_dynamics_v4.html (ось голономии; 4-кольцевая частица).

## 8. 4-кольцевая частица и эйлерова статика (3 ноя, ночь) — ноутбук, разд. 12–13
1. 4 вложенных кольца [посчитано]: период 4π (у каждого кольца b→−b за 2π) — по критерию статьи фермион.
   Поперечный диполь 2(1−ρ)R против 2R у пары ⇒ мощность излучения ∝ (1−ρ)², τ₄ = τ₂/(1−ρ)²
   (ρ=0.7: в 11 раз дольше, но излучение остаётся). Энергия, равновесный ρ — не посчитаны.
2. Эйлерова статика с тензором Альманси [посчитано]: прямая клиновая дисклинация (ось голономии),
   плоская деформация, полярная симметрия, Гук на Альманси (как в Vyvod.ipynb), стрельба по R(r_c):
   - Ω = 0.02: совпадает с линейной теорией (0.4%) — проверка метода;
   - |Ω| = 1–2 рад: напряжения отличаются от линейных на 20–46%;
   - Ω = ±π: статическое решение этим методом НЕ найдено.
   Вывод [вывод, не доказательство]: «Гук на Альманси» при больших сжатиях, вероятно, теряет
   эллиптичность; для π-дисклинации нужен другой определяющий закон (гиперупругий, напр. нео-Гук,
   или с конечной жёсткостью при сжатии) или другой метод (конечные элементы). Динамика (вращающееся кольцо) не решалась.
